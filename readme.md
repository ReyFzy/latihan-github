**MANUAL BOOK**

1. Pengenalan
Website Pelayanan Tata Usaha (TU) adalah website yang bertujuan untuk memberikan layanan online kepada masyarakat yang ingin mengetahui atau mendaftarkan siswa nya di SMKN 2 BANDUNG. Selain itu, dalam pelayanan ini juga berisi pelayanan lain seperti pencetakkan kartu pelajar, pengumuman kelulusan, dsb.

2. Halaman
Dalam web ini terdapat 6 halaman, yaitu berisi:
    - halaman beranda (index.html)
    - Layanan (layanan.html)
    - Kegiatan (kegiatan.html)
    - Pengumuman (pengumuman.html)
    - Kontak (kontak.html)
    - About Us (about.html)

3. Fungsi
fungsi web ini adalah untuk memberikan layanan online kepada masyarakat agar mempermudah masyarakat untuk mengetahui tentang sekolah SMKN 2 Bandung.
